# Codebook vector-quantization papers

These are the exact paper versions supplied for the codebook quantization
implementation:

- `diffusion_product_quantization_2411.12306v1.pdf` — *Diffusion Product
  Quantization*, arXiv:2411.12306v1.
- `vq4all_universal_codebook_2412.06875v1.pdf` — *VQ4ALL: Efficient Neural
  Network Representation via a Universal Codebook*, arXiv:2412.06875v1.
- `quantization_for_microcontrollers_survey_2508.15008v3.pdf` — *Quantized
  Neural Networks for Microcontrollers: A Comprehensive Review of
  Methods, Platforms, and Applications*, arXiv:2508.15008v3.

The implementation mapping and usage examples are documented in
[`docs/codebook_vector_quantization.md`](../../docs/codebook_vector_quantization.md).
